## What to build

The region picker already generates one card per `REGIONS` entry generically — when
tasks 5/6 add the Jovian records this card row holds four. This task makes the **CSS
layout** hold four cards cleanly (2×2 grid on the 1280×800 desktop menu, 1-column
stack on narrow widths) without touching card semantics, and verifies statuses render
for all regions from their save slots. No region data is added yet — the two current
cards must look and behave as today.
